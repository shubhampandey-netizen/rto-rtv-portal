Import RTO Challans from Excel
Upload a file in the standard format (Date, Invoice number, Product SKU Code, Qty, Unit Price, HSN Code, Customer Name, Shipping Address Line 1/2, City, State, Pincode, GSTIN Number). Rows sharing the same Invoice number are grouped into one challan.
Tax rate defaults to 18% and RTO Reason is left blank on imported challans — edit details afterwards if needed. Item Serial No. is left blank (not present in this format).
Invoice Data (from Finance "Console" sheet)
This indexes every original Sales row by Invoice Number so the New RTO form can auto-fill from it. "Sales Return" rows are skipped — they're not needed for lookup.
Searches your Gmail for "Sales & Sales Return" mail and lets you pick which one to import — the latest, or an earlier month. The first time, Google will ask you to sign in and approve access.
Or upload the file manually
On the New RTO form, type the Original Invoice No. and move to the next field — if it's been indexed here, Dispatch From, State, Pincode, Invoice Date, and all items auto-fill. Tax Rate defaults to 18% since it isn't directly given in this sheet — adjust per item if needed.

Challan Numbering
Numbers auto-increment each time a challan is saved. The challan number is built as Prefix + zero-padded number (no extra characters added) — include any "/" or "-" you want directly in the Prefix, e.g. Prefix "RTO/DC/" with 3 digits produces "RTO/DC/083".
Data
This register is shared — every team member using this portal sees the same records and sequence numbers.

Paste Data from Excel

Copy a single column from Excel (including multiple rows) and paste it into the matching box below. Each box lines up by row position — line 1 in every box becomes item 1, line 2 becomes item 2, and so on. Leave any box empty to skip it. Existing items in the form will be replaced.
